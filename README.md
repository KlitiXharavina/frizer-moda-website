# Frizer MODA Website

Official responsive website for **Frizer MODA**, a barbershop in Gjakovë, Kosovo, established in **1992**.

The website was designed and developed to modernize the barbershop's online presence and allow customers to view services, explore previous work, find the shop, and book appointments online.

## Live Website

https://klitixharavina.github.io/frizer-moda-website/

## Features

- Responsive desktop and mobile design
- Mobile hamburger navigation
- Online appointment booking with Setmore
- Services with prices and appointment durations
- Haircut gallery
- Google Maps integration
- Click-to-call functionality
- WhatsApp integration
- Instagram integration
- Opening hours and contact information
- SEO metadata
- Open Graph social sharing metadata
- Lazy-loaded gallery images
- Smooth navigation between sections

## Development

The project was built from scratch using HTML, CSS and JavaScript.

Git was used for version control, while GitHub hosts the source code and GitHub Pages provides the production deployment.

The website follows a responsive, mobile-first-friendly approach and uses the black and gold visual identity of Frizer MODA.
